Como instalar

No PC

  1. Baixe o arquivo do Windows (.exe).
  2. Abra o arquivo “HyperMovesLauncher-v1-Windows.exe”.
  3. Se o Windows avisar, clique em “Mais informações” → “Executar assim mesmo”.
  4. Escolha a versão e clique em Jogar. O Java certo é baixado sozinho.

No celular

  1. Se tiver o Amethyst ou o HyperMoves v1 instalado, desinstale antes.
  2. Toque em “Baixar APK v1.1” e abra o arquivo baixado.
  3. Permita instalar apps desta fonte quando o celular pedir.
  4. Abra o HyperMoves, escolha a versão e jogue. O Java certo é baixado sozinho.
